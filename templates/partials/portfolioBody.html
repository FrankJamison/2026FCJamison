2006 Analog Clock Project

A self-contained HTML/CSS/JavaScript project that renders two animated analog clocks in SVG: one for the viewer’s local time and one for UTC. The clock hands update every second using simple rotation math and CSS transforms, with a clean responsive layout that adapts from side-by-side to stacked on smaller screens. Includes automatic display of the user’s local time zone abbreviation when available.
